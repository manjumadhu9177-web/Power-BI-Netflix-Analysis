NETFLIX DATA ANALYSIS USING POWER BI

Project overview :
    This project focuses on analyzing Netflix content data and customer ratings using POWER BI to indentify trends and gain meaningful insights through interactive dashboard.

Tools Used :
     1.Power BI
     2.Microsoft Excel

Project Objectives :
      1.Analyze the distribution of Movies and TV Shows.
      2.Identify country-wise content distribution.
      3.Analyze genre-wise content.
      4.Explore year-wise content trends.
      5.Undestand Rating Analysis.

Dasboard Analysis :
      1.Total Movies and TV Shows.
      2.Content Type Distribution.
      3.Country-wise Analysis.
      4.Genre-wise Analysis.
      5.Customer Ratings Analysis.

Key Insights :
      1.Analyzed Netflix content distribution.
      2.Identified popular content categories.
      3.Explore country-wise content availability.
      4.Studied content trends over different years.
      5.Analyzed customer rating patterns.

Conclusion :
      This Project provides a clear understanding of netflix content trends and customer ratings through interactive Power BI visualizations.
